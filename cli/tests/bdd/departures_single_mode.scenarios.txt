Feature: Single-mode departures

Scenario: location query prints a single-mode departures table
Given the Helsinki Moves API departures fixture is "location bus departures"
When the user runs hm with arguments:
"""
-l "Vihdintie 17"
"""
Then stdout contains "Vihdintie 17, Helsinki — Vihdintie — Bus departures"
And stdout contains "LINE  DEST         DEPARTS  STOP"
And stdout contains "57    Munkkiniemi  3 min    Vihdintie (Vi0234)"
And stdout contains "58    Kamppi       15:20    Vihdintie (Vi0234)"
And stderr is empty
And exit code is 0
