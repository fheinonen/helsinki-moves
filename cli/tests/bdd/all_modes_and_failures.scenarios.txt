Feature: hm CLI all modes and failures

  Scenario: all modes merge departures from available modes
    Given geocoding finds "Pasila, Helsinki"
    Given bus and tram departures are available across all modes
    When the user runs hm with arguments:
      """
      -l Pasila --all
      """
    Then the departures API is called 4 times
    And the first departures API request has query parameter mode set to "BUS"
    And the second departures API request has query parameter mode set to "TRAM"
    And the third departures API request has query parameter mode set to "RAIL"
    And the fourth departures API request has query parameter mode set to "METRO"
    And stdout contains "Pasila, Helsinki — All departures"
    And stdout contains "MODE"
    And stdout contains "57"
    And stdout contains "9"
    And exit code is 0

  Scenario: all modes ignore invalid single-mode flags
    Given geocoding finds "Pasila, Helsinki"
    Given bus departures are available across all modes
    When the user runs hm with arguments:
      """
      -l Pasila --all -m ferry
      """
    Then stdout contains "Pasila, Helsinki — All departures"
    And stdout contains "57"
    And exit code is 0

  Scenario: all modes warn when one mode is unavailable
    Given geocoding finds "Pasila, Helsinki"
    Given bus departures are available while tram is unavailable across all modes
    When the user runs hm with arguments:
      """
      -l Pasila --all
      """
    Then the departures API is called 4 times
    And stderr contains "Warning: tram departures unavailable"
    And stdout contains "57"
    And exit code is 0

  Scenario: all modes with no departures exit one
    Given geocoding finds "Pasila, Helsinki"
    Given no departures are available across all modes
    When the user runs hm with arguments:
      """
      -l Pasila --all
      """
    Then stderr contains "No upcoming departures at Pasila, Helsinki."
    And exit code is 1

  Scenario: all modes with every mode unavailable warn and exit one
    Given geocoding finds "Pasila, Helsinki"
    Given every mode is unavailable across all modes
    When the user runs hm with arguments:
      """
      -l Pasila --all
      """
    Then the departures API is called 4 times
    And stdout contains "Pasila, Helsinki — All departures"
    And stderr contains "Warning: bus departures unavailable"
    And stderr contains "Warning: tram departures unavailable"
    And stderr contains "Warning: rail departures unavailable"
    And stderr contains "Warning: metro departures unavailable"
    And stderr contains "No upcoming departures at Pasila, Helsinki."
    And exit code is 1

  Scenario: single-mode departures API failure exits two
    Given geocoding finds "Pasila, Helsinki"
    Given the departures API returns an internal server error for single-mode queries
    When the user runs hm with arguments:
      """
      -l Pasila
      """
    Then stderr contains "Could not reach Helsinki Moves API. API error (500): Internal Server Error"
    And exit code is 2
